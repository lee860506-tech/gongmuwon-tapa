합격온

개인정보처리방침

시행일: 2026년 10월 19일 · 버전 1.0

‘합격온’(이하 “앱”)은 국가직 9급 공무원 시험 공부를 돕는 개인 학습 앱입니다. 앱은 회원가입·로그인이 없고, 이용자의 개인정보를 수집·저장·전송하거나 제3자에게 제공하지 않습니다.

1. 수집하는 개인정보

없습니다. 앱 운영자는 이름, 연락처, 이메일, 기기 식별자, 위치, 광고 ID 등 어떠한 개인정보도 수집하지 않습니다. 광고·분석(애널리틱스)·추적 도구를 사용하지 않습니다.

2. 기기 안에만 저장되는 학습 기록

문제 풀이 결과, 오답노트, 메모, 붙여넣은 글, 첨부한 사진·스크린샷(축소본), 북마크, 체크리스트, 연속 학습 기록, 설정은 이용자 기기의 브라우저 저장소(localStorage)에만 저장되며 서버로 전송되지 않습니다. 앱을 삭제하거나 브라우저·앱 데이터를 지우면 함께 삭제됩니다. ‘마이 → 데이터 백업’으로 이용자가 직접 파일로 내보낼 수 있으며, 이 파일은 이용자가 관리합니다.

3. 카메라·사진 접근

‘사진으로 추가’와 ‘스크린샷 첨부’ 기능을 이용자가 직접 실행할 때에만 사진 촬영 또는 갤러리 선택 창이 열립니다. 선택한 이미지는 기기 안에서만 축소·글자 인식(OCR)에 사용되고, 외부 서버로 업로드되지 않습니다. 앱은 백그라운드에서 카메라나 사진에 접근하지 않습니다.

4. 클립보드

‘클립보드에서 붙여넣기’ 버튼을 이용자가 누를 때에만 클립보드의 글자·이미지를 읽어 해당 메모에 넣습니다. 읽은 내용은 기기에만 저장됩니다.

5. 외부에서 내려받는 파일

항목내용
글꼴(Pretendard)화면 글꼴을 jsDelivr CDN에서 내려받습니다. 인터넷이 없으면 기기 기본 글꼴을 씁니다.
글자 인식 엔진(Tesseract.js)과 한국어·영어 인식 데이터OCR을 처음 실행할 때 jsDelivr CDN에서 내려받아 기기에서 실행합니다. 이미지는 전송하지 않습니다.
웹 버전 호스팅웹 버전은 GitHub Pages에서 제공됩니다.

이 과정에서 파일을 내려받기 위한 일반적인 인터넷 통신 정보(IP 주소, 브라우저 정보 등)가 해당 서비스 제공자(jsDelivr, GitHub)에 전달될 수 있으며, 이는 각 제공자의 정책을 따릅니다. 앱 운영자는 이 정보를 받거나 보관하지 않습니다.

6. 음성 읽기(TTS)

영단어 발음은 기기에 내장된 음성 합성 기능을 사용합니다.

7. 아동의 개인정보

앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

8. 이용자의 권리

모든 기록은 이용자 기기에만 있으므로, 이용자는 언제든지 앱 데이터 삭제 또는 앱 삭제로 기록을 지울 수 있습니다. 운영자에게 열람·삭제를 요청할 개인정보는 존재하지 않습니다.
